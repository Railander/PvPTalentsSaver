# PvP Talents Saver

Super lightweight addon that automatically saves your PvP talents with each talent loadout and switches them back when you switch loadouts.

## Usage

No configuration needed — install the addon and it works automatically. Change your PvP talents or switch loadouts as usual; the addon remembers each loadout's PvP talents and reapplies them when you return to it.

## Compatibility

- World of Warcraft: Midnight (12.1.5)

## Credits

PvP Talents Saver is based on the original [PvP Talents Saver](https://github.com/guicaulada/PvPTalentsSaver) project, with fixes and updates for current game versions. Your saved loadouts carry over.
